# Student Management System

A simple console-based Student Management System developed using Java as part of the CodeNova Java Programming Internship.

## Features

- Add new student records
- View all students
- Search students by ID
- Update student details
- Delete student records
- Calculate grades based on marks
- Save student records in a CSV file
- Load saved records when the program starts
- Validate student details

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections
- File Handling
- CSV Data Storage

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the Java files:

   `javac Student.java Main.java`

5. Run the application:

   `java Main`

## Project Files

- `Student.java` — Stores student details and calculates grades.
- `Main.java` — Contains the menu and student management operations.
- `students.csv` — Stores student records.
